# fridgeshare-marketing

Marketing site for [FridgeShare](https://fridgeshare.com).

Built with [Astro](https://astro.build) and [Tailwind CSS](https://tailwindcss.com).

## Dev

```sh
npm install
npm run dev
```

## Deploy

Build the static site and deploy the generated `dist/` directory with the host configured for `fridgeshare.com`.

```sh
npm run build
```
